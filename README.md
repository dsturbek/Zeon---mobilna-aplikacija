# Zeon---mobilna-aplikacija
Zeon je Android aplikacija u Kotlinu za praćenje fitness ciljeva i povezivanje trenera i klijenata. Građena na troslojnoj arhitekturi uz Room/SQLite bazu, Coroutines i Flow, aplikacija omogućuje upravljanje prehranom, praćenje kalorijskog unosa u realnom vremenu te dinamički dohvat zdravih recepata i planova treninga putem eksternih API-ja.
